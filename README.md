# 今日空管 AI 快报

面向塔台运行人员的全球空管资讯日报。它可部署为手机可访问的网页，并通过 GitHub Actions 每天自动从官方来源白名单生成一份新的快报。

## 当前能力

- 展示 3–6 条来自全球官方空管/民航机构的资讯，强化中国与亚太内容；
- 每条并列英文来源要点与中文翻译；
- 展示 AI 关注判断、重要级别、运行影响和建议动作；
- 支持按“重点 / 跟踪 / 参考”筛选；
- 每条均可跳转英文官方来源核验。
- 增加“技术雷达”：有重要新技术动态时报道动态，否则用一个空管术语完成每日学习；
- 支持查看最近 60 期历史日报；
- 自动更新失败时，网页保留上一期内容。

## 内容边界

快报中的英文为来源标题与必要信息摘录，不复制整篇原文。重要运行信息应通过链接中的官方原文、航行情报、气象预报及本单位指令再次核验。对于无法获得英文原文的中国官方资讯，系统会明确标识“中文官方原文 + AI英文译文”。

## 开始使用

本地直接双击 `index.html` 可查看样例版。完整移动端部署与每日自动更新步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

部署前可运行：

```text
npm install
npm run validate
```

首次在线生成前，需要在 GitHub 仓库 Secrets 中配置 `OPENAI_API_KEY`。密钥不会进入网页或代码库。
